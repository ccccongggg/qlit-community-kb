## 到校交通

- **机场 / 高铁站 → 学校**：地铁 X 号线转公交 Y 路，约 50 分钟；打车约 40 元。
- **市内**：公交 Z 路直达校门口，末班车 21:30。

## 校内出行

- 校区内步行 / 自行车为主，共享单车在校门有停放点。
- 跨校区班车：工作日整点发车，关注后勤公众号时刻表。

## 常用目的地

- **最近的医院**：XX 医院，公交 X 路 3 站，急诊 24h。
- **火车站**：地铁 X 线直达，预留 40 分钟。
- **商圈 / 景点**：见「周边美食地图」。

## 出行提醒

- 节假日离校高峰，提前买票、错峰出发。
- 打车用正规平台，记下车牌与行程分享。
