## 到校当天

- 先到学院迎新点报到，领校园卡、宿舍钥匙、体检表。
- 校园卡充值：食堂 / 超市通用，先充够一周饭钱。
- 宿舍水电、洗衣机、空调遥控到楼管处办理。

## 必办清单

- [ ] 校园卡激活与充值
- [ ] 银行卡 / 学费代扣确认
- [ ] 图书馆借阅权限开通
- [ ] 校园网 / WiFi 账号注册
- [ ] 手机号校园套餐（可选）

## 一周内熟悉

- 食堂分布与营业时间（早中晚高峰错峰）
- 教学楼、实验楼、图书馆位置
- 校医院 /  pharmacy 位置与门诊时间
- 最近的公交 / 地铁站与打车点

## 防坑提醒

- 校内推销、低价办卡、二手群交易务必核实身份。
- 贵重物品随身，宿舍离开锁门。
- 加错「班级群」可能是诈骗群，以辅导员发的为准。
