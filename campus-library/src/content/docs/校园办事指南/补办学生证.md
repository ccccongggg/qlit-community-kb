## 适用场景

学生证遗失、损毁或信息变更（如转专业后学院变更）时需要补办。

## 办理步骤

1. 到二级学院学工办开具「学生证遗失/补办证明」，并登记。
2. 在校园卡中心或指定窗口领取空白学生证，贴好一寸照片。
3. 填写个人信息（姓名、学号、学院、专业、有效期）。
4. 学院盖章 → 学生处（或教务）审核盖章。
5. 缴纳工本费（以本校公示为准），等待制证，约 3–7 个工作日领取。

## 所需材料

- 本人身份证 / 校园卡
- 一寸近期免冠照片 1 张
- 学院开具的补办证明

## 注意事项

- 火车票优惠磁条需单独办理 / 充磁，补办后记得重新绑定。
- 旧证找回后应交回注销，不得继续使用。
- 考试季前办理高峰，建议错峰。
