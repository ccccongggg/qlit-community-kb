> 本篇为**示例模板**，具体学分与课程以本校最新培养方案为准。

## 为什么要先读培养方案

培养方案是你毕业的「总账本」：毕业需要多少总学分、各类别（通识 / 专业基础 / 专业核心 / 实践）各需多少、有哪些必修课和限选课。先读它，选课才不迷路。

## 关键字段速读

- **毕业总学分**：通常在 150–170 之间，分学期规划。
- **课程类别**：通识选修、学科基础、专业核心、集中实践等，每类都有最低学分要求。
- **先修课程（Pre）**：很多专业课有前置，没修过不能直接选。
- **开课学期**：同一门课可能不是每年都开，错过要等下一年。

## 怎么用它规划

1. 下载本专业的培养方案 PDF（教务处官网）。
2. 用表格列出每学期打算修的课，确保类别学分不偏科。
3. 标出有 Pre 要求的课，排好先后顺序。
4. 对照「课程评价」模块看往届反馈，避开公认的「雷课」高峰期。

## 注意事项

- 培养方案可能逐年微调，以你入学年份版本为准。
- 转专业 / 辅修的同学，注意学分替换规则。
