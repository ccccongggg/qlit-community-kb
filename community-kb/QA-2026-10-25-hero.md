# 2026-10-25 首屏交互修订

针对浏览器批注：移除商标小球右侧容器，扩展首屏交互。

## 首屏构图补充修订

- 首屏高度改为动态视口减导航高度，跑马灯固定在首屏底边；下一节在滚动后出现。
- 搜索框并入标题与按钮所在的内容组；互动工具移到右下角，弱化背景网格、光晕与按钮阴影。
- 浏览器核对 1363×819、1920×1080、390×844、375×667 的底边偏差小于 1px，无横向溢出；另对矮屏横向布局收紧字号与间距。

## 修改

- 移除 hero-play 容器及边框；画布与整个首屏等宽，以跑马灯上沿作为地面。
- 拖拽保留抓取偏移，用最近 110ms 的真实指针移动估算抛掷速度；增加旋转、碰撞与柔和冲击波。
- 新增“再抛一次”和“开启失重／恢复重力”；鼠标点击首屏空白处可推动小球。
- 搜索框、主按钮与互动控制条作为物理障碍；链接和表单输入优先响应，不被小球拖动逻辑抢占。
- 鼠标移动带来轻微背景偏移；手机只在命中商标时阻止滑动，其他区域保留页面滚动。
- 首屏不可见或标签页进入后台时暂停绘制；遵循系统减少动态效果设置。

## 验证

- 独立物理回归：桌面与手机尺寸各模拟 1,200 帧，覆盖强冲击、失重切换、边界约束和按钮障碍。
- 专项回归确认小球可从 x=900 运动到 x<600，不存在右侧隐藏墙。
- 本地浏览器验证重抛和失重按钮反馈，画布与首屏范围一致，旧容器已不存在。
- 构建与站内检查通过。新增物理回归已并入 npm run check。
