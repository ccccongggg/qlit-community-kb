# 关于这个空间

这是齐鲁理工 WorkBuddy 校园社群的知识与协作网站。公开页面提供学习资料、问题记录、活动信息和成员介绍。

## 内容状态

标记「示例」的文章用于说明内容形式，不代表真实活动或已验证成果。真实项目应附适用条件、来源与可核对的成果。

## 投稿与署名

只提交你有权公开的文字和素材。署名与授权在投稿时说明，未经确认不代表投稿者同意额外的转载授权。发现错误、版权或展示问题，请走[纠错入口](/participate/?type=纠错)。

## 隐私与外部服务

站内搜索和草稿整理在浏览器内完成。主题偏好保存在本机浏览器；访问 WorkBuddy 分享链接时，访问参数会保存在会话中以保持导航可用。

点击 GitHub 提交入口会前往第三方平台；只有你在那里确认提交后，内容才会作为公开 Issue 发布。不要在公开投稿中包含私人联系方式、证件、内部资料或未经同意的个人照片。

成员公开资料由本人确认后维护。需要更正或撤下时，可联系组织者或使用纠错入口。
