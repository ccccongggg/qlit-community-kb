# 2026-10-24 社群知识库改版

## 本地实现

- 首页缩短首屏，搜索前置，物理商标收进独立区域；保留昼夜主题和四大板块，增加近期活动、精选知识和真实问题入口。
- 知识库直接显示文章，按类型筛选并按关键词过滤；问题库改为有状态的内容列表。
- 增加独立新人指南、参与页面、全文搜索、关于与内容规则。
- 提问、加入意向、投稿、活动咨询和纠错使用统一草稿入口，支持下载、复制和跳转真实 GitHub Issue 页面。不会自动发布，也不会虚报成功。
- 活动使用 ISO 时间与自动星期，生成稳定详情页。浏览器根据截止与结束时间更新状态，报名需要有效链接。
- 社群大佬更名社群伙伴，去除技能百分比；资料未确认的成员暂不进入列表，旧网址保留提示页。
- 新增新人清单、提问教程、投稿规范、项目复盘模板、可运行课程表教程和独立课程表示例。
- 五篇原文章标注示例，修正问题案例中未核实的数据；旧活动记录保留到 docs/archive。
- CMS 增加摘要、作者、精选、状态、问题进展、成员公开确认与活动报名字段，减少维护时直接编辑 HTML。
- CSS/JS 和模板图片改为内容哈希缓存；暂停不可见首屏的物理动画，保留减少动态效果适配，修复分享参数与锚点组合。
- 增加站内链接与资源检查、活动时间和数据字段验证、GitHub 构建检查工作流与预览产物。
